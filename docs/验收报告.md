## 桌面流程覆盖

首次打开的真实空状态；通过界面添加三个工具的数据源；重复刷新不重复计数；今日和近七天总量；跨日期的同小时下钻；返回完整筛选范围；保存价格；CSV 预览、映射、币种和导入；恢复导入时区；重复导入；只有日期的记录不进入小时明细；导出标记；重启后来源、价格和用量保留。

文件选择和保存对话框在自动化中指定到隔离测试文件；其他界面操作、IPC、解析和数据库使用真实实现。测试数据位于 `.test-data`，不会进入正常启动的数据库或发行包。

## 审查中发现并修复的问题

- 原生日志改名或轮转后，记录 ID 不稳定导致重复计数。
- Codex 累计值与单次值不一致时错误归入最新时刻；现在优先单次值并提示差异。
- CSV 相同行、不同文件重叠和导入时区变化导致的重复统计。
- WSL 路径斜杠写法绕过运行状态检查。
- 本机与 WSL 刷新同时请求时漏掉一种范围。
- 超长对话行阻断后续正常用量读取。
- 日志异常提示在没有新内容的刷新后消失。
- 旧消息快照覆盖较新消息用量。
- 只有日期的记录错误出现在小时柱对应明细中。

上述问题均有针对性回归检查。独立审查报告保留在项目开发记录中。

## 数据边界

测试不能补齐数据源本身缺失的用量。部分 Codex 会话没有用量事件；Cursor 仅 CSV；OpenClaw 仅 JSONL；费用为估算或来源申报，并非账单。这些限制在界面和 README 中说明。
